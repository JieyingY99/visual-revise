## 0. 产品定位

在**任意网页**上做可视化改稿，最终产出一段 **AI 能精确定位到源码的提示词**。

它不是设计工具，也不是 DevTools 的替代品。它解决的是这样一件事：
产品或设计看着线上页面说「这里间距大了、这个字重不对、这块要能 hover 上浮」，
而这些话传到工程师那里时，既没有确切的元素定位，也没有确切的数值。

边界：
- 所有改动只发生在**当前页面的运行时**，不写回源码、不持久化到服务器
- 刷新页面即全部消失（改动可导出为 JSON 带走）
- 面向的是「描述清楚要改什么」，不是「改完就上线」

## 1. 安装与唤起

| AC | 验收标准 |
|---|---|
| AC-1.1 | 点击扩展图标可唤起编辑器；再点一次收起 |
| AC-1.2 | `Alt+Shift+D` 与点击图标等价 |
| AC-1.3 | 收起后再次唤起，之前的改动记录仍在（同一标签页内） |
| AC-1.4 | 在 `chrome://`、扩展商店等受限页面唤起时，给出明确失败反馈而不是静默无反应 |
| AC-1.5 | 同一页面重复注入不会叠出第二套 UI |
| AC-1.6 | 注入失败留下的死元素不会永久挡住后续唤起（能自愈） |

**已知约束**：扩展重载后必须刷新页面才会加载新代码——`<script type="module">`
按 URL 去重，同一页面只执行一次。构建时间戳会打印在 console，用于确认版本。

## 2. 模式体系

四个互斥模式，外加一个隐身态。工具条上是一组 segmented control。

| 模式 | 键 | 做什么 |
|---|---|---|
| 浏览 | `V` | 把页面交还给用户，正常点击、滚动、交互 |
| 选择 | `A` / `F` | 默认模式。`A` 落到面板的「选择元素」tab，`F` 落到「结构」tab |
| 评论 | `C` | 点击元素写下交互需求，可连续标注多个 |

**重排不再是模式**：结构树并入属性面板的「结构」tab，同一个元素的属性与它在
结构里的位置在一处看。页面上直接拖子元素的能力保留，跟着「结构」tab 开关。

| AC | 验收标准 |
|---|---|
| AC-2.1 | 四个模式键切换正确，工具条高亮跟随 |
| AC-2.2 | 模式键**幂等**：连按 `C` 一直停在评论模式，不 toggle 回选择态 |
| AC-2.3 | 浏览模式下点击页面元素不会被选中，页面自身的交互正常工作 |
| AC-2.4 | 浏览模式下评论 pin 隐藏——它们有 `pointer-events`，留着会挡住该位置的点击 |
| AC-2.5 | 浏览模式下工具条保留，否则进去就出不来 |
| AC-2.6 | 浏览模式下移动鼠标不会画出任何标尺线 / 测距线 |
| AC-2.7 | `Tab` 进入隐身态：连工具条一起藏，再按一次回到原模式 |
| AC-2.8 | 隐身态下除 `Tab` 外所有按键放行给页面（此时用户在用这个网站，不能占着单字母键） |
| AC-2.9 | `Esc` 从任何模式回到选择态 |
| AC-2.10 | 属性面板与结构树的 `×` 都只收起自己那块 UI，**不改变当前模式**——用户多半还想接着做同一件事；关闭整个编辑器是工具条上那个 `×` 的事 |
| AC-2.12 | 结构是面板里的一个 tab 而非模式：`F` 打开、`A` 切回，当前模式始终是「选择」 |
| AC-2.13 | 面板只在选中元素后出现，因此未选中时没有结构树入口 |
| AC-2.14 | 「结构」tab 打开时启用页面直接拖拽；切回「选择元素」tab 则关闭 |
| AC-2.15 | 深层嵌套不撑爆面板：宽度恒为 300，标题栏与 tab 不被挤出视口，树可纵向滚动、横向滚动 |
| AC-2.16 | 拖拽进行中按 `Esc` 取消这一次拖拽，不落下任何 `order` |
| AC-2.17 | 共享元素开启时，在结构里重排会同步到每个同构容器（按下标映射） |
| AC-2.11 | 切换模式不会丢失已有的改动记录 |

## 3. 元素选择

| AC | 验收标准 |
|---|---|
| AC-3.1 | 单击选中元素，显示选中框与元素标签 |
| AC-3.2 | `Shift` + 单击多选；再次 `Shift` 单击已选中的元素则取消它 |
| AC-3.3 | hover 时显示悬停框与标签，不影响已选中项 |
| AC-3.4 | 插件自身的 UI（工具条、面板、评论层）永远不可被选中 |
| AC-3.5 | `Enter` 选中第一个子元素，`Shift+Enter` 选中父元素（层级下钻 / 上浮） |
| AC-3.6 | `Shift+'` **向外扩展**：把父元素加进选中集，原来的子级仍保留（上游语义，不是替换） |
| AC-3.7 | `⌘⇧Enter` 选中当前元素的所有子元素 |
| AC-3.8 | `⌘E` 选中下一个同类元素，`⌘⇧E` 一次选中全部同类 |
| AC-3.9 | `⌘D` 原地复制选中元素 |
| AC-3.10 | `⌘⌥C` / `⌘⌥V` 复制、粘贴样式 |
| AC-3.11 | `Esc` 取消全部选中 |
| AC-3.12 | 选中元素后属性面板出现在元素旁边（见 §5） |

## 4. 快捷键

分三层，冲突时按这个顺序裁决：

1. **修饰键组合**（`⌘Z` 等）—— 在最前面处理，不受模式影响
2. **本插件的单字母键** —— 仅在工具条可见时归插件
3. **页面自己的键** —— 隐身态下全部放行

| AC | 验收标准 |
|---|---|
| AC-4.1 | `⌘Z` / `⌘⇧Z` 撤销重做（Windows 上 `⌘Y` 也认） |
| AC-4.2 | 在输入框里打字时，单字母键不触发插件功能，字符正常输入 |
| AC-4.3 | 在输入框里 `⌘Z` 让路给浏览器的文本撤销，不撤掉整次改稿 |
| AC-4.4 | 焦点停在插件面板内（例如刚点过工具条按钮）时，单字母快捷键**仍然可用** |
| AC-4.5 | 面板内的 `Tab` 与 `Esc` 归面板（切焦点、关弹窗），不被插件抢走 |
| AC-4.6 | 上游 VisBug 的 13 个工具热键（`g i x l m p a v h d f e s`）已解绑，不会在背后切换工具 |
| AC-4.7 | `L` 开合改动记录、`P` 复制提示词 |
| AC-4.8 | `Delete` / `Backspace` 删除选中元素，且只删一个（不触发上游的重复回调） |

## 5. 面板摆位

面板固定在一个地方，位置只由用户决定。早先的版本按选中元素的矩形算左右侧，
本意是别盖住正在改的东西，结果每换一个元素面板就跳一次——眼睛每次都得重新
找它，比偶尔被挡住更累。

| AC | 验收标准 |
|---|---|
| AC-5.1 | 属性面板固定出现在同一个位置（默认右上、工具条下方），**不**跟着选中的元素移动 |
| AC-5.2 | 拖动面板后位置记进 `localStorage`；换选元素、关掉面板再打开、刷新页面重新注入，都回到那个位置 |
| AC-5.3 | 任何情况下面板都不会超出视口：拖动时实时夹取，窗口变小后挤回视口内，重新拉大时回到记住的位置 |
| AC-5.4 | 默认位置不与工具条重叠（横排、竖排都是） |
| AC-5.5 | `localStorage` 被禁（无痕窗口 / 站点策略）时读写都不抛，面板退回默认位置照常可用 |
| AC-5.6 | 结构 tab 打开时面板仍在视口内 |
| AC-5.7 | 滚动页面时面板**不**跟着动（它是 fixed 的） |

| AC-5.8 | 工具条可在横排 / 竖排之间切换（第一格那个按钮），选择记在 localStorage，下次注入沿用 |
| AC-5.9 | 竖排时按钮文字收进 hover 气泡，气泡从按钮下方挪到右侧 |
| AC-5.10 | 竖排时分段控件的滑块沿纵轴移动，仍贴合当前模式 |

**已知取舍**：位置存的是页面自己的 `localStorage`，所以记忆按站点隔离——
在 A 站拖过的位置不会带到 B 站。bundle 以 `<script type="module">` 插进页面、
跑在主世界，够不着 `chrome.storage`；为一个坐标再搭一条
主世界 → content script → background 的消息通道不划算。

## 6. 属性面板（逐控件）

面板分 7 组。每个控件操作后必须**立刻**落到元素的 inline style 上，并进入改动记录——
这是整个工具的产出通道，任何一处"看起来改了、其实没写"都是最坏的 bug。

| AC | 验收标准 |
|---|---|
| AC-6.1 | Position：定位下拉写 `position`；X / Y 写 `left` / `top`；旋转写 `rotate`；层级写 `z-index`；X 前缀可横向拖着调值 |
| AC-6.2 | Layout 排列：四个分段各写 `display`（block / flex+column / flex+row / grid）；换行钮切 `flex-wrap` |
| AC-6.3 | 尺寸：W / H 输入写 `width` / `height`；比例锁开着时改 W，H 按锁定时的比例跟着变 |
| AC-6.4 | 对齐九宫格：点 (col,row) 写 `justify-content` / `align-items`，三档为 flex-start / center / flex-end |
| AC-6.5 | 间隔写 `gap` |
| AC-6.6 | 内 / 外边距：两段式输入分别写左右对、上下对；展开钮后四个方向各自可写 |
| AC-6.7 | 裁剪内容：勾上写 `overflow: hidden`，取消是**清掉声明**而不是写 visible |
| AC-6.8 | Appearance：不透明度写 `opacity`，圆角写 `border-radius` |
| AC-6.9 | Typography：字体下拉只换栈首；字重下拉、字号、行高、字距各写对应属性；对齐四段写 `text-align`；「更多」展开后 `text-transform` / `text-decoration-line` 可写 |
| AC-6.10 | Fill：填充控件同时写 `background-color` 与 `background-image`（不再单独给背景图一行文本框）；文字色写 `color` |
| AC-6.16 | 每个颜色控件都有**色值**和**不透明度**两个独立输入；改色值不会把已调好的不透明度重置回 100% |
| AC-6.17 | 色盘 / 填充等弹层始终夹在视口内，内容变高（如切到渐变）后重新让位 |
| AC-6.11 | Stroke：颜色 / 宽度 / 样式各写 `border-*`；box-sizing 分段写 `box-sizing` |
| AC-6.12 | Effects：`box-shadow` / `filter` / `backdrop-filter` 三个输入各自可写 |
| AC-6.13 | 以上每一次写入都进改动记录（记录数递增），且面板标签变成"已改"色 |
| AC-6.14 | 分组标题上的「重置本组」只在该组改过时出现，点了把本组全部还原；「临时关闭本组」可开关 |
| AC-6.15 | Typography 与 Effects 默认折叠，减少首屏噪音；选中**文字元素**时 Typography 自动展开 |
| AC-6.18 | 「临时关闭本组」关掉的属性跟着该组**这次真的渲染出来的字段**走：选中直接承载文字的元素时 Fill 首行是字色，关组要连字色一起关（只关背景等于没关，这类元素本就没有背景）；纯容器则不动 `color`——那一行没渲染，且 `color` 会继承进整棵子树 |
| AC-6.19 | 填充控件在**纯色**态下与文字色控件同形：色值、不透明度两个可直接编辑的输入，色块与输入框尺寸逐项相同；其余三态（无填充 / 渐变 / 背景图）没有单一色值可填，退回只读摘要标签 |
| AC-6.20 | 颜色类控件点输入框是敲值、不弹色盘（事件跨 shadow 边界会把 `target` 重定向到 host，得看 `composedPath`）；点色块才开弹层 |
| AC-6.21 | 面板里每个图标按钮的图标在按钮方框内水平垂直都居中（`<button>` 的 UA `padding: 1px 6px` 必须显式清掉，否则 border-box 下内容盒被压窄、图标溢出后居中退化成左对齐） |

## 7. 内容操作

改的不只是样式：文案、图片、元素本身的去留和顺序，都要能改、能记、能撤、能导出。

| AC | 验收标准 |
|---|---|
| AC-7.1 | 文案：进入编辑态后键入，改动作为「文案改动」单独记录，不混进样式属性；撤销可回到原文 |
| AC-7.2 | 换图：图片元素的 Fill 组有换图按钮，选文件后 `src` 变成新图；背景图元素走 `background-image` 通道；记录里不被 dataUrl 撑爆 |
| AC-7.3 | 删除：`Delete` 删掉选中元素，记录里留下标签 / 文本特征 / 子元素数；能从记录放回原位；放回后记录消失 |
| AC-7.4 | 页面拖拽重排：重排模式下拖 flex/grid 子元素，落点写 `order`；中途 Esc 取消不留任何改动 |
| AC-7.5 | 结构树重排：树里拖行同样写 `order`，页面与树保持一致 |
| AC-7.6 | 共享元素：开启后改一处，结构相同的兄弟同步；面板显示「联动 N 个」；关闭后只改选中项 |

## 8. 记录与导出

工具的终点是一段 AI 能拿去改源码的提示词。记录必须完整、可回退、可带走。

| AC | 验收标准 |
|---|---|
| AC-8.1 | 改动记录列表：按元素分组，属性 / 文案 / 评论 / 删除各自有计数；hover 列表项在页面上高亮该元素 |
| AC-8.2 | 单条撤销：列表里可撤销某一条属性改动，其它改动不受影响 |
| AC-8.3 | 撤销 / 重做栈：不同属性各自入栈；一次拖拽 / 切排列是一个动作，⌘Z 整体退回 |
| AC-8.4 | 评论：评论模式点元素弹输入框，保存后页面出 pin 并编号；点 pin 可编辑；可删除 |
| AC-8.5 | 参考图：评论里可通过选文件 / 粘贴 / 拖拽加图，逐张移除，带说明一起保存 |
| AC-8.6 | 提示词：包含元素定位、属性改动、独立的「文案改动」「删除的元素」「图片替换」段落，以及摘要计数 |
| AC-8.7 | JSON：导出带 schema 版本；导入后改动重新应用到页面、记录数一致 |
| AC-8.8 | 跨重渲染：框架把节点整个换掉后，改动一帧内重新找回并施加到新节点；不会贴到长得一样的邻居上 |
| AC-8.9 | 重置：清掉所有记录（含已失联的），页面恢复 |
